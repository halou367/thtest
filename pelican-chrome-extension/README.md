# 鹈鹕模型鉴定器 · Chrome 悬浮窗插件 (v1.3.0)

当你浏览大模型对话页（Arena.ai、Claude、ChatGPT、Gemini、DeepSeek 等）或任意网页时，插件会**自动捕获页面中的 SVG / HTML 代码（特别是命中关键词特征的代码）**，同时也支持一键复制自动监听，即刻弹出精简悬浮面板完成渲染预览、模型鉴定与纠错入库。

---

## ✨ v1.3.0 更新亮点

1. **网页 SVG / HTML 代码自动捕获 + 关键词特征精准触发**：
   - 全自动监听页面流式生成与 DOM 渲染完成事件（覆盖 `<pre><code>` 代码块、CodeMirror 编辑器、`iframe[srcdoc]`、`blob:` / 跨域预览沙盒 iframe 以及页面独立渲染的 `<svg>` 插画，自动过滤按钮小图标）。
   - **内置关键词特征识别引擎**：支持中英文大小写与驼峰词边界精准匹配（默认词库：`鹈鹕, pelican, 自行车, bicycle, bike, 骑行, 单车, 喉囊, 脚踏, 车轮, 辐条, 车把, 鸟喙, pouch, beak, pedal, handlebar, wheel, spoke, crank, saddle`），可在悬浮窗右上角 **`🎯`** 按钮或设置页自由增删关键词、切换“仅限命中关键词自动弹出 / 全部代码自动捕获”。
   - **多样本标签切换条**：同一页面捕获到多份代码时（如 Arena 左右双模型盲测对战），面板顶部自动显示 `#1 HTML 🎯鹈鹕` / `#2 SVG 🎯单车` 快捷切换条；也可随时点击面板右上角 **`🔍 本页`**（或右键菜单 / `Alt+Shift+P`）一键抓取全页代码。
2. **极简悬浮面板设计**：
   - 主界面仅保留 **纯净实时预览舞台 + 全部/开源/闭源过滤条 + 合一鉴定结果卡**（模型、置信度、强度档位、关键词命中徽章 `🎯` 一目了然）。
   - 推理强度分布与 Top-5 候选列表收折进 `详情 ▾` 抽屉，按需展开。
3. **一键纠正与归档入库 (`/api/v1/samples`)**：
   - 点击 **`✎ 纠正 / 入库`** 即可点选候选芯片或指定厂商（Claude / GPT / Gemini / Qwen / DeepSeek / GLM / Kimi 等）、型号与推理强度（`LOW / MED / HIGH / MAX`），直接向后端提交样本并同步馆藏数据集。
4. **渲染与剪贴板稳定性**：
   - 修复 MV3 沙盒 CSP 嵌套 `iframe` 限制，增加 `renderId` 握手去重与 SVG 即时内联兜底渲染；拦截富文本剪贴板 `1.7 KB` 碎片包裹污染。

---

## 🚀 安装 / 更新步骤（15 秒完成）

1. 拉取最新仓库代码后，在 Chrome 地址栏打开：`chrome://extensions/`
2. 打开右上角 **「开发者模式 (Developer mode)」**
3. 若首次安装：点击左上角 **「加载已解压的扩展程序」**，选择 `pelican-chrome-extension` 文件夹；若已安装：点击插件卡片上的 **「刷新 🔄」** 按钮，并刷新已打开的测试网页即可生效。
