# 鹈鹕实验室 · SVG/HTML 剪贴板模型鉴定器 (Chrome Extension MV3)

自动检测剪贴板中的 **SVG** 或 **HTML** 源码，直连 `https://th.629717.cc.cd`（默认密码 `1234567890`）进行模型归属与推理强度鉴定，在页面右下角弹出**实时渲染预览小窗口**并**注释模型型号**，内置**全部 / 开源 / 闭源药丸切换按钮**。

## 安装步骤（Chrome / Edge / Brave / Arc）

1. 下载并解压 `pelican-chrome-extension.zip` 到本地文件夹（确保文件夹内直接包含 `manifest.json`）。
2. 打开浏览器地址栏输入：`chrome://extensions`（Edge 输入 `edge://extensions`）。
3. 打开右上角的 **开发者模式 (Developer mode)** 开关。
4. 点击左上角 **加载已解压的扩展程序 (Load unpacked)**，选择解压后的文件夹即可。
5. **注意**：安装完成后，已打开的旧网页需**刷新一次 (`F5`)** 以注入剪贴板监听脚本；新打开的网页自动生效。

## 四种触发方式

1. **网页点击“复制代码”按钮自动弹出**：在 Arena、ChatGPT、Claude、DeepSeek、Kimi、GitHub 等任意网页点击代码块的复制按钮（或选中 `<svg>...` / `<!DOCTYPE html>...` 按 `Ctrl+C` / `Cmd+C`），右下角立即弹出预览鉴定小窗。
2. **外部软件复制切回浏览器自动识别**：在 VS Code / 微信 / 记事本复制 SVG 或 HTML 代码后，切回浏览器窗口即自动检测弹出。
3. **点击浏览器右上角 `鹈` 扩展图标**：自动读取当前剪贴板并预览鉴定，也可点击 **「粘贴源码」** 手动粘贴测试，或点击 **「⚙」** 修改服务器地址与密码。
4. **快捷键 / 右键菜单**：按 `Alt + Shift + P`（或选中代码右键 → `使用鹈鹕实验室鉴定选中的 SVG / HTML 模型`）随时触发。
