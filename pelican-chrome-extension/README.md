# 鹈鹕实验室 · SVG/HTML 剪贴板模型鉴定助手 (v1.2.0)

自动检测剪贴板中的 **SVG** 或 **HTML** 源码，直连 `https://th.629717.cc.cd`（默认密码 `1234567890`）进行模型归属与推理强度鉴定，弹出**极简无遮挡实时预览面板**，并支持**一键纠正/归档同步入库**。

## v1.2.0 优化亮点

1. **极简合一面板设计**：去除原本遮挡画面的底部浮层与三处重复的模型/强度卡片，收敛为「无遮挡实时预览 + 开源/闭源过滤条 + 单张合一鉴定结果卡」，Top-5 概率与强度细节按需点击「详情 ▾」展开。
2. **新增「✎ 纠正 / 入库」功能**：识别完成后点击 **「✎ 纠正 / 入库」**，可直接点选候选快选气泡或选择 **厂商 / 型号 / 推理强度 (LOW·MED·HIGH·MAX)**，一键提交至 `POST /api/v1/samples` 写入云端样本库（自动区分「纠错入库」与「确认归档」并实时刷新本地结果与历史）。
3. **修复预览空白与剪贴板漏读/误读问题**：
   - 严格过滤浏览器富文本剪贴板 `text/html`（`<!--StartFragment-->`）包装层，仅提取真实 `text/plain` 源码；支持 `about:srcdoc` 等内嵌预览框内的复制按钮实时捕获。
   - 统一异步复制轮询时序：等待系统剪贴板哈希真正更新后再触发，彻底解决「复制后读到旧剪贴板」与「重复复制同一份代码变空白」的问题。
   - 双引擎预览：新增 `manifest.json` 沙箱 CSP 授权 + `renderId` 幂等去重 + `864×540` 桌面视口自适应缩放 + Shadow DOM 原生矢量瞬时兜底，在严格 CSP 网站上也不会白屏。

## 安装与更新步骤（Chrome / Edge / Brave / Arc）

1. 拉取或下载本仓库，打开浏览器访问 `chrome://extensions`（Edge 访问 `edge://extensions`）。
2. 开启右上角 **开发者模式 (Developer mode)**。
3. 点击左上角 **加载已解压的扩展程序 (Load unpacked)**，选择仓库中的 **`pelican-chrome-extension`** 文件夹（若已安装旧版，覆盖代码后点击扩展卡片上的 **刷新 ↻** 按钮即可）。
4. **注意**：更新扩展后，请将已打开的网页 **刷新一次 (`F5`)** 以使新版剪贴板脚本生效。
