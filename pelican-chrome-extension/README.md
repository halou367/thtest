# 鹈鹕模型鉴定器 · Chrome 悬浮窗插件 (v1.5.0)

当你浏览大模型对话页（Arena.ai、Claude、ChatGPT、Gemini、DeepSeek、Kimi、Qwen、豆包等）或本地预览网页时，插件会**自动捕获当前页的 SVG / HTML 绘图代码**，即刻弹出极简悬浮面板完成渲染预览、模型鉴定与纠错入库。

---

## ✨ v1.5.0 更新亮点（极简 UI）

1. **极简悬浮窗**：去掉左上角名称/品牌标、全部彩色徽章（金银牌、关键词、开源思考、馆藏等）、开源/闭源过滤条、详情抽屉、关键词抽屉。只保留核心内容：
   - 顶部：`本页` 重新扫描 + 最小化 + 关闭
   - 预览舞台（悬停出现「放大」）
   - 模型名 + 概率 + 一行小字（`开源/闭源 · 强度`，已入库时追加）
   - `纠正 / 入库`（点开后：厂商 / 型号 / 强度 / 确认入库）
2. **最多 2 个当前页样本**：样本切换条最多显示最近 2 个（`#1 HTML 48.4K` / `#2 HTML 42.8K`），按捕获时间倒序，精准抓取当前页面的 SVG/HTML。
3. **换页即清空**：页面地址变化（普通跳转或 SPA 的 popstate/hash 变化）时立即清空全部样本、鉴定结果与窗口，绝不残留历史页面的内容。
4. 保留 v1.4.0 的 Arena.ai 折叠预览小窗恢复（Blob + React Fiber，仅最新一轮）与多主题关键词全捕获（大嘴鸟/白鸽/摩托车/鹈鹕等）。

---

## 🚀 安装 / 更新步骤

1. `git pull` 拉取最新仓库代码后，在 Chrome 地址栏打开：`chrome://extensions/`
2. 打开右上角 **「开发者模式 (Developer mode)」**
3. 点击「鹈鹕模型鉴定器」卡片上的 **「刷新 🔄」** 按钮，再刷新已打开的页面即可生效。
