# 鹈鹕模型鉴定器 · Chrome 悬浮窗插件 (v1.3.1)

当你浏览大模型对话页（Arena.ai、Claude、ChatGPT、Gemini、DeepSeek、Kimi、Qwen、豆包等）或本地预览网页时，插件会**自动捕获页面中的 SVG / HTML 绘图代码（涵盖鹈鹕、大嘴鸟、白鸽、摩托车、单车等多主题特征及无注释纯图形代码）**，同时也支持一键复制自动监听，即刻弹出精简悬浮面板完成渲染预览、模型鉴定与纠错入库。

---

## ✨ v1.3.1 更新亮点

1. **多主题视觉评测特征词库 + 智能全捕获双引擎（`v1.3.1` 升级）**：
   - **大幅扩充内置特征词库**：全面覆盖 **鹈鹕 (`pelican`)、大嘴鸟/巨嘴鸟 (`toucan`)、白鸽/和平鸽/鸽子 (`dove`, `pigeon`)、火烈鸟/企鹅/猫头鹰/鹦鹉/天鹅 (`flamingo`, `penguin`, `owl`, `parrot`, `swan`)** 等鸟类/动物主题，以及 **摩托车/机车/重机/踏板车 (`motorcycle`, `motorbike`, `moto`, `scooter`, `vespa`)、自行车/单车/三轮车/滑板 (`bicycle`, `bike`, `tricycle`, `skateboard`)** 与 **头盔、排气管、引擎、大灯、轮胎、车轮、车把、鸟喙、喉囊、翅膀、羽毛 (`helmet`, `exhaust`, `engine`, `headlight`, `tire`, `wheel`, `handlebar`, `beak`, `bill`, `pouch`, `wing`, `feather`)** 等高频解剖与机械结构特征。
   - **代码 + 对话上下文双重特征提取**：不仅匹配 SVG/HTML 源码内的标签、注释与驼峰 ID，还能结合代码块/预览框旁边的对话提示词（如提问“画一只骑摩托车的大嘴鸟”而模型仅输出纯 `<path>` 坐标），照样精准识别并标注 `🎯 大嘴鸟·摩托车`。
   - **默认开启「智能全捕获」并支持旧配置自动平滑迁移**：所有代码块（`<pre><code>`）、预览沙盒（`iframe[srcdoc]` / 跨域预览帧）、本地 `.html`/`.svg` 文件及 AI 对话页内的完整 SVG/HTML 视觉作品**默认全部自动触发识别**（命中特征词的样本优先排在第一位），同时精准过滤普通网页的小图标与非绘图碎片。
2. **极简悬浮面板设计 + 多样本标签切换**：
   - 同一页面捕获到多份代码时（如 Arena 左右盲测对战），顶部自动出现 `#1 HTML 🎯大嘴鸟` / `#2 SVG 🎯白鸽` 快捷切换条；也可随时点击 **`🔍 本页`** 或快捷键 `Alt+Shift+P` 主动扫描。
3. **一键纠正与归档入库 (`/api/v1/samples`)**：
   - 点击 **`✎ 纠正 / 入库`** 即可点选候选芯片或指定真实模型与推理强度（`LOW / MED / HIGH / MAX`），直接同步入库。

## 🚀 安装 / 更新步骤

1. `git pull` 拉取最新仓库代码后，在 Chrome 地址栏打开：`chrome://extensions/`
2. 打开右上角 **「开发者模式 (Developer mode)」**
3. 点击「鹈鹕模型鉴定器」卡片上的 **「刷新 🔄」** 按钮（旧版配置会自动迁移合并新词库并开启全捕获），再刷新已打开的测试网页即可生效。
